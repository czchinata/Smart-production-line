用于柔性作业车间调度问题（FJSP）的端到端深度强化学习
在产线智能调度的开发过程中，面对柔性作业车间调度（FJSP）这一核心难题，重点参考并引入了 Lei 等人提出的多动作端到端深度强化学习框架作为关键技术支撑。
传统调度方法在面对大规模或实时性要求极高的产线场景时，往往受限于计算复杂度而难以落地；而现有的部分 DRL 方法仍依赖于人工设计的调度规则，泛化能力有限。该项目所提出的 Multi-PPO 算法及基于图同构网络（GIN）的析取图编码机制，成功实现了无需预定义规则的端到端自主决策，且具备不受实例规模限制的优良特性。这一“无模型”架构不仅有效解决了工序选择与机器分配的多动作协同决策问题，更为我们将调度算法从静态基准测试向动态、复杂的真实工业产线迁移提供了坚实的理论基础与代码实现路径。我们在项目中借鉴了其多重 Actor-Critic 网络设计思路，显著提升了调度系统的响应速度与解的质量，特此致谢并推荐后续研究者关注该工作。
